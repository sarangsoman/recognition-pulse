About this data. Every number here comes from a dataset I generated with a script, not from a real company. The shape follows how recognition platforms are described publicly: employees synced from an HR system, peer and manager recognition with points, redemptions, and an automatic milestone feed.

The nudge test is planted: I chose its effect when generating the data, so the page shows how I analyse a test, not what a real test would find. Reproduce it with generate_data.py and build_dashboard_data.py.
